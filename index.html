SELECTED WORK

Projects with purpose.

OceanEmbed — Subsurface Temperature Reconstruction

Built a PyTorch CNN encoder–decoder to reconstruct Bay of Bengal subsurface temperatures from SST, SSH, and SSS inputs. Generates 76 × 76 maps across 14 depth levels (0.5–700 m), achieving 1.420°C RMSE — 12.3% below the climatology baseline.

Live Demo GitHub

Dental CBCT Tooth Segmentation Pipeline

Developed a 2D U-Net pipeline for 3D CBCT tooth segmentation, trained on 14,790 slices from 50 volumes. The 7.7M-parameter model achieved a 0.7479 Dice score and 0.6948 IoU, with interactive 3D visualisation of predictions.

Live Demo GitHub

Turbofan Predictive Maintenance System

Used NASA C-MAPSS engine data to build an RUL prediction and anomaly-detection pipeline. Random Forest and XGBoost achieved R² = 0.79 for RUL prediction, F1 = 0.87, and recall = 0.93; served through FastAPI and React.

Live Demo GitHub

AI Interview Prep Platform

Created a MERN-based interview preparation platform that generates role-specific questions and supports pinned questions for revision. Includes JWT authentication, protected routes, session expiry, and a deployed React interface.

Live Demo GitHub

Heart Disease Risk Assessment
